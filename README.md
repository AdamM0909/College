# 🎓 College Tracker

A simple website for keeping track of the colleges I'm looking at — ratings, costs, application requirements, distance, deadlines and personal notes.

**Live site:** https://adamm0909.github.io/college/ (after GitHub Pages is turned on — see below)

## Features

- **Personal rating** — 1–5 stars for each college
- **Pricing** — tuition, room & board, scholarships/grants, with an auto-calculated net cost per year
- **Application info** — plan (ED/EA/RD/Rolling), deadline, fee, platform, GPA and test-score notes
- **Requirements checklist** — default list (essays, transcript, recs, etc.) that you can tick off, plus your own custom items
- **Distance & location**, acceptance rate, intended major, reach/target/safety category
- **Status tracking** — Researching → Planning → Applied → Accepted / Waitlisted / Rejected → Committed
- **Pros, cons and personal notes**
- **Dashboard** — totals, next deadline, total application fees, top-rated school
- **Search, filter and sort**, plus a **Compare** table view to see everything side by side
- **Dark mode**
- **Export / Import** to a JSON file for backups or moving to another device

## Turning on GitHub Pages

1. Go to the repo on GitHub → **Settings** → **Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Pick the branch (e.g. `main`) and the `/ (root)` folder, then **Save**.
4. After a minute the site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Where is my data stored?

Everything is saved in your browser's local storage — nothing is uploaded anywhere, so it's private.
That also means it's tied to that one browser. Use **Export** regularly to download a backup,
and **Import** to load it on another computer or phone.

## Running locally

Just open `index.html` in a browser. No build step or installs needed.
